# Contributing to DeSci Lab

## Reviewing Hypotheses
All hypotheses in `hypotheses/` are open for expert review. To submit feedback:
1. Open an Issue with the label `peer-review`
2. Cite the specific hypothesis ID and your reasoning
3. Include your domain expertise and any conflicting/supporting literature

## Suggesting New Domains
Open an Issue with label `domain-suggestion` and link at least 3 recent high-impact papers.

## Code / Scripts
PRs welcome for improvements to the literature scanning and hypothesis generation pipeline.
